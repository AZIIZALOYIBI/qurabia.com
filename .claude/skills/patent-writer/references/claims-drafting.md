# مرجع صياغة المطالبات التفصيلي
## Claims Drafting — Advanced Reference

---

## 1. قواعد صياغة المطالبة المستقلة

### 1.1 البنية القانونية الصحيحة

```
[مقدمة Preamble]   → تُعرِّف بفئة الاختراع وغرضه
[انتقال Transition] → يحدد نطاق الحماية (مفتوح/مغلق)
[جسم Body]        → يُعدّد العناصر الضرورية والكافية
```

**مثال صحيح (عربي):**
```
"جهاز لمعالجة إشارات الاستشعار البيئي، يتضمن:
  وحدة استشعار (10) مُهيَّأة لاستقبال إشارات حرارية وضوئية؛
  وحدة معالجة (20) مُتصلة بوحدة الاستشعار (10) ومُهيَّأة لتحويل
    الإشارات إلى بيانات رقمية؛ و
  وحدة إخراج (30) مُتصلة بوحدة المعالجة (20) وقادرة على
    إرسال البيانات الرقمية إلى شبكة خارجية."
```

**مثال خاطئ:**
```
"جهاز رائع ومبتكر لمعالجة إشارات البيئة بطريقة فريدة..."
← خطأ: "رائع" و"فريد" لا معنى قانوني لهما
```

## 2. كلمات الانتقال — تحديد نطاق الحماية

### 2.1 الانتقال المفتوح (مُفضّل دائماً تقريباً)

```
عربي: "يتضمن" / "يشتمل على" / "مؤلف من ما يشمل"
إنجليزي: "comprising" / "including" / "having"

المعنى: قد يحتوي المنتج على عناصر إضافية وتبقى المطالبة منتهَكة
المثال: جهاز يتضمن A وB → جهاز فيه A وB وC ينتهك المطالبة ✓
```

### 2.2 الانتقال المغلق (استخدامه نادر جداً)

```
عربي: "يتكوّن حصراً من" / "يتألف فقط من"
إنجليزي: "consisting of"

المعنى: لا يجوز وجود عناصر إضافية
الاستخدام: التركيبات الكيميائية فقط تقريباً
الخطر: المنافس يضيف عنصراً بسيطاً ويتهرب من الانتهاك
```

### 2.3 الانتقال شبه المغلق

```
عربي: "يتكوّن أساساً من"
إنجليزي: "consisting essentially of"

المعنى: لا عناصر إضافية تُغيّر الخصائص الجوهرية
الاستخدام: صيدلة وكيمياء في حالات خاصة
```

## 3. صياغة المطالبات التابعة

### 3.1 قالب المطالبة التابعة

```
"جهاز وفقاً للمطالبة [N]، حيث تكون [العنصر] مُهيَّأ/ة لـ [تفصيل إضافي]."

أو لإضافة عنصر جديد:
"جهاز وفقاً للمطالبة [N]، يتضمن إضافةً [عنصر جديد] مُتصلاً بـ [عنصر موجود]."
```

### 3.2 استراتيجية بناء هرمية المطالبات

```
المطالبة 1 (مستقلة — أوسع):
  يتضمن: A + B + C

المطالبة 2 (تابعة لـ 1 — تُضيّق A):
  وفقاً للمطالبة 1، حيث A يكون من نوع X

المطالبة 3 (تابعة لـ 1 — تُضيّق B):
  وفقاً للمطالبة 1، حيث B يكون كذا وكذا

المطالبة 4 (تابعة لـ 2 — تُضيّق أكثر):
  وفقاً للمطالبة 2، حيث يكون X مُدمجاً مع Y

← هذا يبني "سلسلة دفاعية": حتى لو سقطت المطالبة 1،
   قد تبقى المطالبات 2 و3 سارية
```

## 4. أنواع المطالبات المستقلة المتعددة

### 4.1 الثالوث الاستراتيجي (Apparatus + Method + System)

```
مجموعة الجهاز (Apparatus Claims):
  المطالبة 1: جهاز يتضمن...
  → تُنتهك بالصنع أو البيع أو الاستخدام

مجموعة الطريقة (Method Claims):
  المطالبة N: طريقة لـ..، تتضمن:
    الخطوة الأولى: استقبال...؛
    الخطوة الثانية: معالجة...؛
    الخطوة الثالثة: إرسال...
  → تُنتهك بالممارسة الفعلية للخطوات

مجموعة النظام (System Claims):
  المطالبة M: نظام يشمل خادماً وعميلاً مُهيَّأين لـ...
  → تُنتهك حين يعمل النظام الكامل معاً
```

### 4.2 مطالبات وسائل-وظيفة (Means-Plus-Function) — بحذر

```
صيغة: "وسيلة لـ [تنفيذ وظيفة معينة]"
إنجليزي: "means for [performing function]"

الخطر: تُفسَّر ضيقاً جداً بما يُكافئها في الوصف
النصيحة: استخدمها فقط حين لا توجد لغة هيكلية بديلة
```

## 5. صياغة مطالبات البرمجيات والذكاء الاصطناعي

### 5.1 التعامل مع محدودية حماية البرمجيات

```
المبدأ: البرنامج وحده لا يُحمى في السعودية وكثير من دول العالم
الحل: اربط البرنامج بتأثير تقني ملموس

❌ خاطئ: "طريقة لتصفية البيانات باستخدام خوارزمية X"
✓ صحيح: "نظام حاسوبي لتصفية إشارات الاستشعار في الوقت الفعلي
           يتضمن: معالجاً (10) مُبرمجاً لتنفيذ خوارزمية X لتقليل
           زمن الاستجابة دون 10 ميلي ثانية في إشارات البيئة الصناعية"
```

### 5.2 صياغة مطالبات الذكاء الاصطناعي

```
النهج المُوصى:
  - ركّز على الأثر التقني: "تحسين دقة التصنيف بنسبة X%"
  - صف البنية التقنية: "شبكة عصبية ذات طبقتين على الأقل مُهيَّأة لـ..."
  - اذكر التطبيق الصناعي المحدد: "في مجال التشخيص الطبي / قيادة المركبات / ..."
  - تجنّب المطالبات المجردة: "نظام تعلم آلي لتحسين النتائج" ← مرفوض
```

## 6. المطالبات الكيميائية والصيدلانية

### 6.1 تركيب / مركّب كيميائي

```
"مركّب كيميائي بالصيغة [الصيغة الجزيئية]، حيث:
  R1 يُمثِّل مجموعة ألكيل من C1 إلى C6؛
  R2 يُمثِّل هيدروجين أو هالوجين؛
  n يساوي 1 أو 2 أو 3."
```

### 6.2 طريقة تحضير

```
"طريقة لتحضير [المركّب] تتضمن:
  خلط [المادة أ] بـ [المادة ب] بنسبة مولارية من 1:1 إلى 1:3؛
  تسخين الخليط إلى درجة حرارة بين 50 و80 درجة مئوية؛
  ترشيح الناتج للحصول على [المركّب] بنقاء لا يقل عن 99%."
```

## 7. مراجعة المطالبات — قائمة التدقيق النهائية

```
✓ كل مطالبة مستقلة تقف بمفردها دون الحاجة لأي مطالبة أخرى
✓ لا يوجد عنصر في المطالبات غير موصوف في الوصف التفصيلي
✓ الانتقال (comprising/consisting) مناسب ومتسق
✓ كل مطالبة تابعة تُشير بوضوح لمطالبة أم محددة
✓ لا تناقض بين المطالبات المختلفة
✓ الأرقام المرجعية مذكورة في المطالبات (مستحسن في SAIP وإلزامي في بعض الجهات)
✓ جميع التنويعات الرئيسية مُغطّاة بمطالبات تابعة
✓ مطالبات الجهاز والطريقة والنظام تُغطي نفس الاختراع من زوايا مختلفة
✓ لا استخدام لكلمات غير محددة مثل "كثيراً" أو "سريعاً" دون تعريف
✓ عدد المطالبات مناسب (5-25 مطالبة للبراءة المتوسطة)
```

## 8. أخطاء صياغة المطالبات الشائعة

```
الخطأ 1 — المطالبة الواسعة المُفرطة:
  "جهاز لأتمتة العمليات" ← بلا عناصر محددة، سيُرفض
  الحل: أضف عناصر كافية لتمييزه عن الفن السابق

الخطأ 2 — المطالبة الضيقة المُفرطة:
  تفاصيل تنفيذية زائدة تحصر الحماية بشكل غير ضروري
  الحل: ضع التفاصيل في المطالبات التابعة

الخطأ 3 — عدم الإحالة للرسوم:
  المطالبات لا تُشير للأرقام المرجعية عند وصف العناصر
  الحل: أضف (10)، (20) وفقاً للرسوم

الخطأ 4 — الكشف في الوصف دون مطالبة:
  فكرة رائعة في الوصف لكنها لم تُطالَب بها
  الحل: راجع الوصف واستخرج منه كل نقطة قابلة للمطالبة

الخطأ 5 — الجمع بين جهاز وطريقة في مطالبة واحدة:
  "جهاز لـ... ويعمل بطريقة..."
  الحل: جهاز في مطالبة مستقلة، طريقة في مستقلة أخرى

الخطأ 6 — استخدام "يمكن" أو "قد":
  "وحدة قادرة على أن تُعالج..."
  المشكلة: "قد" تعني أنها لا تفعله دائماً
  الحل: "وحدة مُهيَّأة لمعالجة..." أو "وحدة معالجة مُبرمجة لـ..."
```
