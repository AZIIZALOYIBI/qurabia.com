## 3. المطالبات | Claims — التشريح التفصيلي

### 3.1 بنية المطالبة المستقلة النموذجية

```
[Preamble/Premise] — المقدمة:
  "A method for..."  /  "An apparatus comprising..."  /  "A system for..."
  تحدد نوع الاختراع وفئته العامة

[Transition Word] — كلمة الانتقال:
  "comprising"  ← مفتوح (open): يسمح بعناصر إضافية للانتهاك
  "consisting of" ← مغلق (closed): انتهاك يتطلب المطابقة التامة
  "consisting essentially of" ← شبه مغلق

[Body] — الجسم:
  العناصر والخطوات الجوهرية، كل منها في سطر منفصل عادةً
```

**مثال تفصيلي:**
```
Claim 1:
A method for detecting fraudulent transactions [PREAMBLE],
comprising [TRANSITION]:
  receiving, by a processor, transaction data [ELEMENT 1];
  extracting, by the processor, a plurality of features 
    from the transaction data [ELEMENT 2];
  applying a machine learning model to the plurality of 
    features to generate a fraud score [ELEMENT 3]; and
  determining, based on the fraud score, whether the 
    transaction is fraudulent [ELEMENT 4].
```

---

### 3.2 قاعدة All-Elements Rule (قاعدة كل العناصر)

> **الانتهاك يتطلب توافر كل عنصر في المطالبة المستقلة، بالضبط.**

```
المطالبة: A + B + C + D
المنتج المشتبه به:

A + B + C + D = انتهاك مباشر ✓
A + B + C     = لا انتهاك (نقص D) ✗
A + B + C + D + E = انتهاك ✓ (مفتوح بـ comprising)
A + B + C + D + E = لا انتهاك ✗ (مغلق بـ consisting of)
```

---

### 3.3 Doctrine of Equivalents (مبدأ المكافئات)

حتى لو لم يكن العنصر حرفياً، قد يكون مكافئاً إذا:
- يؤدي **نفس الوظيفة**
- بـ **نفس الطريقة**  
- ليُنتج **نفس النتيجة**

(Function-Way-Result Test)

**مهم**: مبدأ المكافئات يُقلَّص بـ "Prosecution History Estoppel" إذا تنازل المُقدِّم عن شيء خلال الملاحقة.

## 4. تاريخ الملاحقة | Prosecution History (File Wrapper)

أهميته في التحليل:
1. يُبيّن ما تنازل عنه المُقدِّم تحت ضغط الفاحص
2. يُضيّق تفسير المطالبات (Prosecution Disclaimer)
3. يكشف ما استُبعد صراحةً من الحماية

**أين تجده:**
- USPTO: Patent Center → Image File Wrapper
- EPO: Register Plus
- WIPO: PatentScope → National Phase Entry Documents

**وثائق المهمة في ملف الملاحقة:**
```
Office Action (OA)     ← اعتراض الفاحص
Response to OA         ← رد المُقدِّم + التعديلات
Examiner Interview     ← نقاشات مباشرة
Notice of Allowance    ← قبول البراءة
RCE (Request for Continued Examination)
Appeal Brief           ← استئناف
```

## 5. العائلات البراءتية | Patent Families

### أنواع العائلات:

```
Simple Family (DOCDB):
  كل الوثائق بنفس الأولوية

Extended Family (INPADOC):
  يشمل التطبيقات المرتبطة حتى لو بأولوية مختلفة

نفس الاختراع يظهر كـ:
  ① WO2020123456 (PCT Application)
      ↓ يتفرع إلى:
  ② US20210012345A1 (US Publication)
  ③ US11234567B2 (US Granted)
  ④ EP3892547A1 (EP Publication)
  ⑤ EP3892547B1 (EP Granted)
  ⑥ CN113412345A (China)
  ⑦ JP2022-123456A (Japan)
  ...إلخ
```

**لماذا مهم**: براءة منتهية في أمريكا قد تكون سارية في أوروبا!

## 6. أنواع البراءات حول العالم

| النوع | المدة | الخصائص |
|-------|-------|---------|
| Utility Patent (اختراع) | 20 سنة | الأساسي، يحمي الوظيفة |
| Design Patent (تصميم) | 15-25 سنة | يحمي المظهر البصري فقط |
| Plant Patent | 20 سنة | أصناف نباتية (أمريكا) |
| Utility Model / Petty Patent | 10-15 سنة | فحص مخفف، بعض الدول |
| SPC (Supplementary Protection Certificate) | +5 سنوات | أدوية/مبيدات، أوروبا |

## 7. الاستشهادات | Citations

### أنواع الاستشهادات:
- **Backward Citations**: ما استشهدت به هذه البراءة (الفن السابق المُعترف به)
- **Forward Citations**: البراءات التي استشهدت بهذه البراءة لاحقاً (مؤشر أهمية)

**أهمية Forward Citations**:
- كثرتها = أهمية تقنية عالية
- تكشف من بنى على هذا الاختراع
- أداة لتحليل المشهد وتتبع التطور

## 8. قراءة التصنيف الزمني للوثائق

```
براءة منتهية بـ 20 سنة من تاريخ تقديمها:
  إذا Filing Date = 2000/01/01
  تنتهي = 2020/01/01
  الآن 2024 → في نطاق الملكية العامة (Public Domain) ✓

براءة مع SPC (دواء):
  Filing Date = 2002
  Expiry = 2022 + 5 SPC = 2027 ← لا تزال سارية!
```
