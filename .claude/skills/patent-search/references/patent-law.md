# قانون البراءات المقارن | Comparative Patent Law
## المعايير القانونية الدولية والاتفاقيات الدولية

---

## 1. الاتفاقيات الدولية الأساسية

### 1.1 اتفاقية باريس (Paris Convention — 1883)
- **المبدأ**: المعاملة بالمثل + حق الأولوية 12 شهراً (براءات)
- **التغطية**: 177 دولة
- **أهم بند**: المادة 4 — الأولوية الدولية

### 1.2 معاهدة البراءات الدولية PCT (Patent Cooperation Treaty — 1970)
```
التقديم الواحد → يتحول إلى طلب في 150+ دولة
المرحلة الدولية: بحث + فحص أولي
المرحلة الوطنية: تُختار خلال 30 شهراً

المزايا:
  - تأجيل التكاليف الكبيرة 30 شهراً
  - تقييم أولي للقابلية قبل الالتزام بتكاليف وطنية
  - تقرير بحث دولي (ISR) + رأي مكتوب (WO)
```

### 1.3 اتفاقية TRIPs (WTO — 1994)
- **الحد الأدنى**: 20 سنة لكل أعضاء WTO (163+ دولة)
- **المتطلبات**: الجدة + الخطوة الاختراعية + التطبيق الصناعي
- **الاستثناء**: الأدوية في الدول النامية (Compulsory Licensing)

## 2. الأنظمة الرئيسية مقارنةً

### 2.1 USPTO — الولايات المتحدة الأمريكية

**القانون الأساسي**: 35 U.S.C. (أُصلح بـ America Invents Act 2013)

```
§101 — قابلية الموضوع للتسجيل (Subject Matter Eligibility)
  ما يُسجَّل: عمليات، آلات، تصنيع، تركيبات
  الاستثناءات القضائية:
    ① ظواهر طبيعية (laws of nature)
    ② ظواهر طبيعية (natural phenomena)
    ③ أفكار مجردة (abstract ideas) ← مشكلة برمجيات!

§102 — الجدة (Novelty)
  نظام First-to-File منذ مارس 2013
  استثناء: إفصاح المخترع خلال 12 شهراً (grace period)
  الفن السابق يشمل: كل ما نُشر قبل تاريخ التقديم في أي مكان

§103 — الخطوة الاختراعية (Non-Obviousness)
  اختبار Graham v. John Deere:
    1. نطاق الفن السابق
    2. الاختلافات بينه وبين الاختراع
    3. مستوى المهارة في المجال (POSITA)
    4. مؤشرات موضوعية (الحاجة التجارية، إخفاق الآخرين...)

§112 — الإفصاح الكافي (Enablement + Written Description)
  يجب أن يُمكّن الوصف أي متخصص من صنع الاختراع واستخدامه
  Best Mode Requirement (واجب الإفصاح الأفضل)
```

**فحص البراءات الأمريكية:**
- متوسط الانتظار: 24-30 شهراً
- رسوم التقديم: ~$830 (مؤسسة صغيرة)
- أدوات الفحص: PTAB للاعتراض بعد المنح

### 2.2 EPO — أوروبا (اتفاقية براءة أوروبا EPC)

**القانون الأساسي**: European Patent Convention (EPC 2000)

```
Art. 52 — قابلية التسجيل
  المستثنى صراحةً:
  - اكتشافات، نظريات علمية، طرق رياضية
  - إنشاء فني (أعمال أدبية، فنية)
  - قواعد وطرق للنشاط الذهني، الألعاب
  - برامج الحاسوب "as such" ← لكن بـ Technical Character يُقبل

Art. 54 — الجدة
  Absolute Novelty: أي نشر في العالم يكسر الجدة
  لا grace period في EPO! (استثناء محدود جداً)

Art. 56 — الخطوة الاختراعية
  Problem-Solution Approach:
    1. أقرب فن سابق (Closest Prior Art)
    2. الفرق التقني (Technical Differences)
    3. الأثر التقني (Technical Effect)
    4. المشكلة الموضوعية (Objective Technical Problem)
    5. هل المشكلة + الحل غير واضح لمختص؟

Art. 83 — الإفصاح الكافي
Art. 84 — وضوح المطالبات (Clarity) ← EPO أكثر صرامة من USPTO
```

**مميزات EPO:**
- براءة موحدة (Unitary Patent) منذ 2023 في 17+ دولة أوروبية
- محكمة براءة موحدة (UPC) للنزاعات
- متوسط الانتظار: 36-48 شهراً

---

### 2.3 JPO — اليابان

```
نظام First-to-File
Deferred Examination: يمكن تأجيل الفحص 3 سنوات
Grace Period: 12 شهراً (مثل USA)
نظام FI/F-term المفصّل للتصنيف
متطلبات عملية تعمل بشكل صناعي (Working Requirement)
```

---

### 2.4 CNIPA — الصين

```
3 أنواع رسمية:
  ① براءة اختراع (Invention Patent): 20 سنة، فحص كامل
  ② نموذج منفعة (Utility Model): 10 سنوات، بدون فحص موضوعي ← سريع!
  ③ تصميم صناعي: 15 سنة

Absolute Novelty (مثل EPO)
Grace Period: 6 أشهر فقط (مؤتمرات + معارض حكومية)
Working Requirement: استخدام في الصين خلال 3 سنوات
Compulsory License في حالات المصلحة العامة
```

## 3. الاستثناءات من الحماية

### 3.1 المستثنى عالمياً:
- اكتشافات ظواهر طبيعية (إلا ما كان مطبقاً تقنياً)
- نظريات علمية ورياضيات مجردة
- طرق علاجية وجراحية على الإنسان/الحيوان (EPO)
- اختراعات تخالف النظام العام والأخلاق

### 3.2 النزاع حول البرمجيات:
```
أمريكا (بعد Alice Corp. 2014):
  برامج لها "inventive concept" وراء الفكرة المجردة = قابلة للتسجيل
  اختبار Alice/Mayo = اختبار ثنائي المرحلة

أوروبا (EPO):
  برامج بـ "Technical Character" = قابلة للتسجيل
  (تحل مشكلة تقنية، لا مجرد أتمتة عمليات تجارية)

الصين: مرونة نسبية إذا كانت مرتبطة بعملية تقنية
```

## 4. انتهاك البراءة | Patent Infringement

### 4.1 أنواع الانتهاك:
```
Direct Infringement (انتهاك مباشر):
  صنع + استخدام + بيع + عرض للبيع + استيراد
  في نطاق الولاية القضائية للبراءة

Indirect Infringement (انتهاك غير مباشر):
  Contributory Infringement: تورط مساهم
  Induced Infringement: تحريض على الانتهاك

Literal Infringement: مطابقة حرفية للمطالبة
DOE Infringement: مكافئات وظيفية
```

### 4.2 الدفاعات ضد الانتهاك:
```
① عدم الانتهاك (Non-Infringement)
② البطلان (Invalidity) — Art. 102/103 قبل تاريخ أولوية البراءة
③ الترخيص (License) — ضمني أو صريح
④ الإرهاق (Laches/Estoppel)
⑤ الاستخدام التجريبي (Experimental Use) — ضيق جداً
⑥ انقضاء قانون التقادم
⑦ Patent Misuse / Antitrust
```

## 5. التقدير الكمي لقوة البراءة | Patent Strength Metrics

```
مؤشر قوة البراءة يعتمد على:
  1. عدد المطالبات المستقلة (أكثر = أشمل)
  2. عرض المطالبة 1 (أقل قيود = أقوى)
  3. عدد الاستشهادات الأمامية (forward citations)
  4. عدد الدول المُشمولة
  5. سريان الحالة القانونية
  6. عدم الطعن فيها قضائياً
  7. تاريخ تقديم مبكر في مجال حديث (البكر التقني)

أدوات القياس: PatSnap Strength Score، Derwent WPI Score
```

## 6. الترخيص والنقل | Licensing & Assignment

```
أنواع الترخيص:
  Exclusive License — حصري (حتى على المالك الأصلي)
  Non-Exclusive License — غير حصري (متعدد)
  Compulsory License — ترخيص إجباري (حكومي)
  Cross-License — تبادلي بين شركتين
  Sub-License — إعادة الترخيص

Patent Pools — مجمع براءات بين منافسين
FRAND — شروط عادلة ومعقولة وغير تمييزية (براءات معايير)
SEP (Standard Essential Patents) — براءات معايير مثل 5G
```
